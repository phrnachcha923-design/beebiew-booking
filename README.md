# BeeBiew Booking — Luxury Pink Premium Edition

เว็บไซต์ HTML/CSS/JavaScript พร้อม Deploy บน GitHub Pages หรือ Vercel

## ใช้งาน
เปิด `index.html` ได้ทันที หรืออัปโหลดโฟลเดอร์นี้ขึ้น GitHub แล้วเชื่อมต่อกับ Vercel

## ระบบจอง
ข้อมูลถูกเก็บด้วย Local Storage ของเบราว์เซอร์ และจำกัด 2 คิวต่อวันในอุปกรณ์/เบราว์เซอร์นั้น

> หากต้องการใช้งานหลายเครื่องและมีแอดมินจริง ควรเชื่อมต่อฐานข้อมูล เช่น Supabase หรือ Firebase


## Logo reliability
The logo is embedded directly in index.html and also included as assets/logo.jpg and assets/logo.png to prevent broken images on Vercel and Safari.
