# BeeBiew Booking

เว็บไซต์จองคิวสไตล์ Luxury Pink พร้อมใช้งานบน GitHub Pages และ Vercel

## คุณสมบัติ
- พื้นหลังชมพูเบลอแบบเคลื่อนไหว
- Glass Effect และ Rose Gold
- Fade In เมื่อเลื่อนหน้าเว็บ
- การ์ดประเภทการจองแบบเลือกได้
- การ์ดสรุปจำนวนคิววันนี้
- จำกัด 2 คิวต่อวัน
- เลือกเวลา 09:00–20:00 น.
- บันทึกคำขอด้วย Local Storage ของเบราว์เซอร์
- รองรับมือถือ

## Deploy บน Vercel
นำโฟลเดอร์นี้อัปโหลดไปยัง GitHub แล้วเชื่อม Repository กับ Vercel หรืออัปโหลดโฟลเดอร์โดยตรงได้เลย

> หมายเหตุ: ระบบ Local Storage จะบันทึกข้อมูลเฉพาะอุปกรณ์และเบราว์เซอร์ที่ใช้งาน หากต้องการให้หลายคนเห็นคิวร่วมกัน จำเป็นต้องเชื่อมฐานข้อมูลหรือบริการ Backend เพิ่มเติม
